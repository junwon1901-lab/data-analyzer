# 📊 데이터 분석 프로그램 (Data Analyzer)

CSV·Excel 파일을 불러와 **선형·비선형 회귀분석**과 **인공신경망 예측**을 수행하는 Streamlit 프로그램입니다.
왼쪽의 분석 모드에서 1차 과제의 회귀 화면과 2차 과제의 신경망 화면을 전환합니다.
입력은 숫자형 표 데이터이며, 모든 파일 형식·데이터에 적용되는 것은 아닙니다.

## 기능
- **파일 불러오기**: CSV, Excel(.xlsx/.xls), 텍스트(.txt/.data)
  - 구분자(쉼표·세미콜론·탭), 한글 인코딩, 천 단위 쉼표, 소수점 쉼표 자동 인식
  - Excel 시트 선택, 열 이름 행 위치 지정 (표 위에 제목이 있는 파일 대응)
- **X/Y축 선택**: 숫자로 된 열 자동 탐지
- **데이터 거르기**: 글자 열(분류)로 원하는 그룹만 선택, X값 범위 지정
- **선형회귀**: y = a·x + b
- **비선형회귀**: 다항식(2~6차), 지수, 거듭제곱, 로그
- **결과**: 회귀식, R², RMSE, MAE, 잔차 그래프, 새 X값 예측
- **모델 비교**: 전체 모델 R² 순위표, CSV 다운로드
- **인공신경망 회귀**: 다중 입력변수, ReLU/tanh, 은닉층·학습률·epoch 설정
- **검증**: 학습/검증/테스트 분리, 학습 데이터만 표준화, 검증 오차 기반 조기 종료
- **그룹 분리**: 같은 선형번호의 모든 행을 한 세트에만 배치 (새 선박에 대한 평가)
- **ANN 결과**: 학습 곡선, 테스트 실제값/예측값·잔차, 동일 조건 선형회귀 기준 모델, 새 입력 예측
- **구조 비교**: 네 가지 은닉층 구조를 같은 조건에서 학습하고 검증 RMSE로 선택 (비교 단계에서 테스트 미평가)
- **학습 원리 확인**: 입력 행 수·변수 수와 X/y 형태, 층별 파라미터 수, 실제 가중합·편향·활성화 계산
- **내보내기**: 구조 비교 CSV·JSON, 예측 CSV, 학습 곡선 CSV, 설정·분리 행 위치·평가 JSON

## 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 인공신경망 빠른 실행

1. 분석 모드에서 **인공신경망 (2차 과제)**를 선택합니다.
2. **선체 저항 전체 변수 (인공신경망용)** 예제가 자동 선택됩니다.
3. 입력 8개, 목표 정규화 저항, 선형번호 그룹 분리를 확인합니다.
4. **구조 비교 실험 실행**을 누르고 검증 RMSE·파라미터 수를 비교합니다.
5. **비교에서 선택한 구조 적용 → 인공신경망 학습 시작**을 누릅니다.
6. 학습된 가중치·편향, 테스트 성능·학습 곡선을 확인하고, 아래 입력폼으로 새로운 값을 예측합니다.

단일 구조만 학습할 때는 비교를 생략할 수 있습니다. 초기 은닉층 설정은 기존 64·32입니다.

Python 3.12에서 검증했습니다. CPU만으로 실행하며 API 키나 유료 AI 서비스가 필요하지 않습니다.
현재 허용 버전 범위는 requirements.txt, 검증한 정확한 버전은 requirements-tested.txt를 참고하세요.

데이터·변수·학습 설정이 바뀌면 결과를 숨기고 재학습을 요구합니다.
같은 세션의 단순 화면 재실행이나 예측 입력 변경으로는 재학습하지 않습니다.
브라우저 새로고침/서버 재시작 이후의 모델 영구 저장 기능은 제공하지 않습니다.

## 주의

- 1차 과제 탭의 R²는 학습에 사용한 전체 데이터의 적합도입니다. ANN의 테스트 R²와 직접 비교하지 마세요.
- 선박 데이터의 목표는 **Rt/Δ × 10³**이며 저항의 단위 N이 아닙니다.
- 기본 그룹 분리는 같은 선박이 여러 세트에 섞이지 않게 합니다. 무작위 행 분리는 그 보장이 없습니다.
- 숫자 목표의 회귀 전용입니다. 분류/미래 시계열 예측을 자동 처리하지 않습니다.
- 학습 범위를 벗어난 예측, 물리적으로 불가능한 입력 조합, 음수 저항 예측에 주의하세요.
- 테스트 결과를 보고 설정을 반복 조정하면 테스트도 간접적으로 학습에 쓰인 셈이 됩니다.
- 최소 30개 유효 행, 최대 50,000행·50개 입력변수의 실습용 한도를 적용합니다.
