## 해석과 한계
- 같은 선박의 행이 학습·검증·테스트에 섞이지 않도록 선형번호로 분리했다.
- R²·RMSE·MAE는 정규화 저항값의 원래 척도로 계산한다. RMSE·MAE의 단위를 N으로 쓰면 안 된다.
- 2·3차 다항식은 입력에 비선형이지만 계수에 선형인 회귀이며, Ridge 규제값은 1이다.
- LLM은 계산기를 호출하는 요청 해석기다. 부정확한 설명이나 잘못된 동작 선택이 가능하다.
- 대화 최근 12개와 분석 요약을 다시 입력한다. 모든 과거 내용을 무제한으로 기억하지 않는다.
- JSON에 기록을 저장할 뿐 LLM 가중치는 재학습하지 않는다.
- 로컬 실행 기록이며 GitHub·Notion 게시 또는 LMS 제출 증명은 아니다.
