# 오픈소스 LLM을 연결한 선체 저항 분석 프로그램

동아대학교 조선해양공학과 서준원

## 1. 과제 목적

1차 과제에서는 선형·비선형 회귀분석을, 2차 과제에서는 여러 입력변수를 사용하는 인공신경망 예측을 구현했다. 이번에는 기존 프로그램에 대화창을 추가해 문장으로 분석을 요청할 수 있도록 확장했다. ‘선형회귀 해줘’라고 입력하면 해당 분석을 실행하고 결과 표와 그래프를 보여주는 방식이다.

11월 6일 강의에서 안내된 오픈소스 LLM 설치와 웹사이트 대화창 연결에 맞춰 공개 모델을 직접 내려받아 실행하도록 구성했다. 기존 분석 데이터를 이용해 LLM 자체를 새로 학습시키는 방식은 아니다.

## 2. 모델 선택과 구성

모델은 Qwen2.5-1.5B-Instruct의 GGUF Q4_K_M 파일을 사용했다. 양자화는 가중치를 더 적은 비트로 표현해 저장 공간과 메모리 부담을 줄이는 방법이며, 이 모델 파일의 크기는 약 1.12GB다.

초기 Ollama 구성에서 무료 서버 배포를 고려한 CPU 실행 방식으로 변경했다. llama-cpp-python이 모델을 실행하고 Streamlit이 대화창과 분석 화면을 제공한다. 외부 유료 AI API는 사용하지 않으며 Hugging Face는 공개 모델 파일을 내려받는 용도로 사용한다. 파일 크기와 SHA-256을 검사한 뒤 모델을 불러온다.

작은 모델은 자원 부담이 적지만 요청을 잘못 이해할 수 있다. 따라서 모델의 답변을 계산 결과로 그대로 쓰지 않고, 요청 해석과 실제 계산의 역할을 나누었다.

## 3. 프로그램 동작

사용자가 질문을 입력하면 LLM은 요청을 대화, 데이터 설명, 회귀분석, 신경망 학습, 모델 비교, 예측 등의 동작으로 분류한다. 프로그램은 응답 형식과 입력값을 검사한 뒤 허용된 Python 함수를 실행한다. 모델이 작성한 임의의 Python 코드를 실행하지는 않는다.

| 입력 예시 | 실행 내용 |
| --- | --- |
| 안녕. 간단하게 인사해줘. | 일반 대화 생성 |
| 선체 저항 데이터를 설명해줘. | 데이터와 입력·출력 정보 표시 |
| 선형회귀 해줘. | 회귀 함수 실행 |
| 신경망을 학습해줘. | 신경망 학습과 테스트 평가 |
| 세 모델을 같은 조건으로 비교해줘. | 선형·다항·신경망 결과 비교 |
| 50 epoch와 500 epoch를 비교해줘. | 학습 상한에 따른 검증 결과 비교 |
| 오차가 큰 예측 10개 보여줘. | 실제값과 예측값의 오차 조회 |

표와 그래프의 수치는 Python 계산에서 나온다. 일반 대화는 최근 메시지 최대 6개, 각 240자까지 참고하므로 모든 대화를 계속 기억하는 구조는 아니다. 대화와 결과를 JSON으로 저장하는 기능도 모델 가중치를 재학습하는 것과는 다르다.

## 4. 데이터와 분석 방법

기존 과제와 같은 Sailboat Hull Resistance Dataset의 정리본을 사용했다. 자료는 1,018행, 21열, 70개 선형으로 구성된다. 입력은 프루드수, 레이놀즈수, 주형계수, 방형계수, 수선면계수, 길이폭비, 폭흘수비, 부심위치의 8개 변수다. 출력은 정규화 저항 Rt/Δ × 10³이며 힘의 단위 N으로 해석하지 않는다.

같은 선박의 측정값이 학습과 테스트에 섞이지 않도록 선형번호로 분리했다. 학습 640행, 검증 176행, 테스트 202행을 사용하며 표준화 기준은 학습 데이터에서 구한다. 신경망은 입력 8개, 은닉층 64–32–16, 출력 1개의 구조다. ReLU, Adam, 학습률 0.001을 사용하고 목표값은 로그 변환과 표준화 후 학습한다.

## 5. 분석 결과

아래 값은 개발 환경에서 실행한 검증 기록이다. 공개 Streamlit 서버에서 측정한 결과와는 구분한다.

| 모델 | 테스트 R² | RMSE | MAE |
| --- | ---: | ---: | ---: |
| 다변량 선형회귀 | 0.8044 | 22.9112 | 18.0864 |
| 2차 다항회귀 | 0.8925 | 16.9841 | 12.4935 |
| 인공신경망 | 0.9259 | 14.1035 | 8.0103 |

같은 입력과 분리 조건에서는 신경망의 오차가 가장 작았다. 다만 R² 0.9259는 정답을 92.59% 맞혔다는 뜻이 아니다. 실제값 109.8753을 55.6093으로 예측한 사례도 있어 전체 지표가 높더라도 개별 예측은 크게 틀릴 수 있다.

학습 상한 50과 500 epoch의 검증 RMSE는 각각 13.6462와 9.8529였다. 상한 500 조건은 실제 157회 학습 후 종료되었고, 검증 오차가 가장 작았던 117회 시점의 가중치를 채택했다. 상한, 실제 학습 횟수, 최종 채택 시점은 서로 다른 값이다. 이 결과만으로 500회가 항상 좋은 설정이라고 일반화할 수는 없다. 같은 테스트 분할을 이전에도 관찰했으므로 새로운 외부 독립 검증으로 볼 수도 없다.

## 6. 대화 기능 검증과 한계

자동 검사 45개가 통과했다. 실제 모델에 보낸 13개 요청 중 12개가 답변 내용까지 포함한 확인 조건을 만족했고, 요청한 동작의 선택은 13개 모두 기대한 결과였다. 회귀·신경망 실행, 새 입력값 예측, 결과 조회, 보고서 생성이 확인되었다. Streamlit 화면 검사에서는 실제 모델을 호출해 표와 그래프 표시 및 방문자별 대화 분리를 확인했다.

실패한 항목은 이름을 다시 묻는 질문이었다. 앞에서 사용자 이름을 알려주었지만 모델이 자신의 이름을 묻는 것으로 해석했다. 현재 프로그램을 장기 대화나 정확한 개인 정보 기억에 적합하다고 보기는 어렵다. 분석 명령도 시험한 문장에서는 작동했지만 모든 표현에서 같은 정확도를 보장하지 않는다.

CPU 2개로 제한한 개발 환경에서 모델 처리 시간은 약 18.3–33.2초, 최대 프로세스 메모리는 약 2.14GiB였다. 최초 다운로드 시간은 별도다. 모델 하나를 공유하고 한 번에 한 요청씩 처리하며, 실제 무료 서버의 자원에 따라 속도와 실행 가능 여부가 달라질 수 있다.

## 7. 사용 방법과 제출 전 확인

1. Streamlit 앱에서 LLM Chat 페이지를 연다.
2. 모델 준비 또는 상태 확인을 눌러 다운로드와 로딩을 마친다.
3. 인사나 간단한 질문으로 대화를 확인한다.
4. ‘선형회귀 해줘’, ‘신경망을 학습해줘’ 등의 요청으로 결과 표와 그래프를 확인한다.
5. 필요한 분석 결과와 대화 기록을 내려받는다.

현재 검증 범위는 개발 환경까지다. 제출 전에는 공개 앱에서 모델 다운로드가 완료되는지, 질문을 반복해도 서버가 중단되지 않는지, 로그아웃 상태나 다른 기기에서도 접속되는지 확인해야 한다. 서버의 파일은 재배포나 절전 복구 과정에서 사라질 수 있으므로 필요한 기록은 따로 내려받는다.

## 8. 정리

기존 회귀·신경망 분석 기능에 자연어 요청을 연결했다. LLM이 요청을 해석하고 Python이 계산하도록 구성해 대화 답변과 실제 분석 수치를 구분했다. 작은 공개 모델도 정해진 분석 기능을 호출하는 데 활용할 수 있었지만 문맥을 잘못 이해하는 답변과 처리 시간의 한계가 남았다.

구현 과정에서 AI를 활용해 코드 수정, 오류 점검과 문서 정리를 진행했다. 위 수치는 AI 작업 환경에 남은 실행 기록을 바탕으로 작성했으며 개인 PC나 공개 서버에서 직접 측정한 수치로 기재하지 않았다.
