## 1. 과제 목적

1차 과제에서 만든 선형·비선형회귀 프로그램에 인공신경망 회귀 기능을 추가하였다.
공개된 선체 저항 데이터를 이용하여 프루드수와 선형 특성 등 여러 입력변수로부터 정규화 저항값을 예측한다.
사용자가 CSV·Excel 파일을 올리고 입력변수와 목표변수를 선택하는 기능도 유지하여, 다른 숫자형 표 데이터로 실습할 수 있게 하였다.

이번 과제의 핵심은 프로그램의 실행뿐 아니라 데이터가 신경망을 거쳐 예측값으로 바뀌는 학습 알고리즘을 설명하는 것이다.
인공신경망을 사용한다고 반드시 선형회귀보다 좋아지는 것은 아니므로, 같은 데이터 조건으로 학습한 선형회귀 기준 모델과도 비교한다.

### 3.1 행 수와 입력 노드 수는 다르다

선체 데이터의 **한 행은 한 선박의 한 속도 조건에서 측정한 관측 1건**이다. 같은 선박에도 여러 행이 있다. 입력변수 8개를 고르면 관측 1건의 입력 벡터는 8개의 숫자로 이루어지므로 입력층 노드는 8개다. 전체 관측이 1,018개여도 입력층 노드가 1,018개가 되는 것은 아니다. 이는 10/2 07:27–08:24, 36:58의 입력·출력 형태 설명과 연결된다.

| 대상 | X 형태: 관측 수 × 변수 수 | y 형태 | 역할 |
|---|---|---|---|
| 정리된 전체 데이터 | (1018, 8) | (1018,) | 전체 관측과 정답 |
| 학습 세트 | (640, 8) | (640,) | 가중치·편향 갱신 |
| 검증 세트 | (176, 8) | (176,) | epoch·구조 선택 |
| 테스트 세트 | (202, 8) | (202,) | 선택 후 평가 |
| 새 관측 1건 | (1, 8) | 예측 결과 (1,) | 입력값 8개로 목표값 1개 예측 |

위 크기는 기본 선체 예제, 선형번호 그룹 분리, 시드 42에 해당한다. 업로드 파일이나 변수 선택·분리가 바뀌면 달라진다. 출력 노드는 1개이며, y를 코드에서 1차원 배열로 저장하는 것은 관측별 정답을 나열하기 위한 표현이다.

### 3.2 내가 정하는 것과 학습이 찾는 것

| 사용자가 선택하는 설정 | 데이터 학습으로 결정하는 값 |
|---|---|
| 어떤 변수를 X와 y로 쓸지, 제외할 열 | 각 연결의 가중치 W |
| 은닉층 수와 각 층의 노드 수 | 각 은닉·출력 노드의 편향 b |
| 활성화 함수, 학습률, 최대 epoch, 분리 기준 | 선택한 구조에서 오차를 줄이는 W와 b의 수치 |

입력·출력 노드 수는 선택한 변수 차원에 맞춰지고, 은닉층은 모델 설계자가 정한다. AI가 은닉층 수까지 가중치와 같은 방식으로 자동 학습하는 구현은 아니다. 네 후보를 비교해 구조를 고르는 과정과 각 후보의 가중치 학습을 구분한다.

## 5. 알고리즘

### 5.1 데이터 정리

선택한 입력변수와 목표변수를 숫자로 변환한다.
이 열들에 결측값·무한대가 있거나 그룹 식별값이 비어 있는 행은 제거하며, 제거한 행 수를 화면에 표시한다.
정답 열이 입력에 포함되거나 목표값이 모두 같은 경우에는 학습을 중단한다.
입력이 모두 일정한 경우에도 중단한다.

실습용 구현 한도는 정리 후 최소 30행, 정리 전 최대 50,000행·50개 입력변수이다.
이는 교수님이 지정한 조건이 아니라 프로그램의 실행 안정성을 위한 설정이다.

### 5.2 학습·검증·테스트 분리

기본 선체 예제에서는 선형번호를 기준으로 분리한다.
같은 선박의 서로 다른 속도 조건이 여러 세트에 섞이면 이미 본 선박에 대한 예측으로 성능을 평가할 수 있기 때문이다.

1. 전체 선박 그룹의 20%를 테스트용으로 분리한다.
2. 나머지 그룹 중 20%를 검증용으로 분리한다.
3. 남은 그룹으로 가중치를 학습한다.

비율은 그룹 수 기준이므로 실제 행 비율이 정확히 64:16:20일 필요는 없다.
학습 데이터는 가중치 갱신에, 검증 데이터는 학습 종료와 최선 모델 선택에만 사용한다.
테스트 데이터는 그 과정에서 사용하지 않고 최종 평가 때만 사용한다.

일반 데이터에서는 무작위 행 분리도 선택할 수 있다.
행 순서 분리는 현재 표의 앞·중간·뒷부분을 순서대로 배정한다. 시간순 정렬은 자동으로 하지 않으므로 사용자가 미리 정렬해야 한다.

### 5.3 표준화

레이놀즈수처럼 큰 값과 계수처럼 작은 값을 함께 학습하기 위해 입력과 목표를 표준화한다.
각 입력변수의 학습 세트 평균 μ와 표준편차 s를 사용한다.

$$
\tilde{x}_j = \frac{x_j-\mu_{x_j}}{s_{x_j}},\qquad
\tilde{y} = \frac{y-\mu_y}{s_y}
$$

평균·표준편차는 반드시 학습 세트에서만 구한다.
검증·테스트·새 입력에도 동일한 학습 통계를 적용하며, 각각의 평균으로 다시 맞추지 않는다.
신경망의 출력은 다음 식으로 원래 목표값 크기로 복원한다.

$$
\hat y = s_y\hat{\tilde y}+\mu_y
$$

변화가 없는 개별 입력열은 StandardScaler에서 나눗셈 스케일을 1로 처리하지만 예측 신호를 제공하지 않는다.

### 5.4 신경망 구조와 순전파

scikit-learn의 MLPRegressor를 사용한다. 기본 구조는 입력 8개, 은닉층 64개·32개 뉴런, 출력 1개이다.
이는 선형식 하나로 표현하기 어려운 여러 입력과 저항 사이의 관계를 학습하기 위한 다층 퍼셉트론이다.

$$
\mathbf h_1=\operatorname{ReLU}(W_1\tilde{\mathbf x}+\mathbf b_1)
$$
$$
\mathbf h_2=\operatorname{ReLU}(W_2\mathbf h_1+\mathbf b_2)
$$
$$
\hat{\tilde y}=W_3\mathbf h_2+b_3
$$

W는 학습하는 가중치, b는 편향이다. ReLU(z)=max(0,z)이며 화면에서 tanh로 바꿀 수도 있다.
출력층에는 값을 0~1로 제한하는 활성화 함수를 사용하지 않아 연속적인 숫자를 예측한다.

기존 기본값 64·32는 10/2 구현 때 정한 출발점이다. 10/3의 구조 비교에서는 검증 RMSE가 더 작은 **32·16**을 선택했다(7.2절). 화면의 초기 기본값은 기존 64·32를 유지하며, ‘구조 비교 실험 실행 → 비교에서 선택한 구조 적용 → 인공신경망 학습 시작’으로 실험 결과를 적용할 수 있다.

32·16 구조에서 학습할 파라미터 수는 다음과 같다. 입력 노드에는 별도의 편향을 두지 않고, 다음 층의 각 노드에 하나씩 편향을 둔다.

| 연결 | 가중치 수 | 편향 수 | 합계 |
|---|---:|---:|---:|
| 입력 8 → 은닉 32 | 8×32 = 256 | 32 | 288 |
| 은닉 32 → 은닉 16 | 32×16 = 512 | 16 | 528 |
| 은닉 16 → 출력 1 | 16×1 = 16 | 1 | 17 |
| 전체 | 784 | 49 | **833** |

scikit-learn의 `coefs_[0]`은 (앞층 노드 수, 다음층 노드 수) 배열이다. 위 수식은 열벡터 표기이므로 코드 배열의 전치가 수식의 W에 대응한다. 코드의 행벡터 계산은 `입력 @ coefs_[층] + intercepts_[층]`이다.

### 5.5 오차 계산·역전파·가중치 갱신

학습 데이터의 실제 표준화 목표와 예측값 차이를 계산하고, 역전파로 가중치에 대한 오차의 변화율을 구한다.
Adam 최적화 방법으로 이 변화율을 이용해 가중치와 편향을 조금씩 갱신한다.
기본 학습률은 0.001, 미니배치 크기는 최대 64행, L2 규제 계수 alpha는 0.0001이다.

MLP 내부 학습은 제곱오차 기반 손실에 가중치 L2 규제를 더한다.
화면의 학습 곡선에는 규제항을 제외한 순수 MSE를 별도로 계산해 표시한다.
가중치 자체를 무조건 작게 만드는 것이 학습의 목적은 아니다. 예측 오차를 줄이는 값을 찾고, L2 규제는 과도하게 큰 가중치를 억제하는 보조 역할을 한다. 10/2 37:58의 불명확한 ‘가중치를 최소’ 표현은 이 구분으로 정리한다.

$$
\mathrm{MSE}=\frac{1}{n}\sum_{i=1}^{n}(\tilde y_i-\hat{\tilde y}_i)^2
$$

epoch는 학습 데이터 전체를 한 번 학습하는 단위이다.
partial_fit을 한 번 호출할 때 한 epoch를 진행하며, Adam의 상태를 유지하면서 반복한다.

### 5.6 검증과 조기 종료

기본 최대 학습 횟수는 500 epoch이다.
매 epoch 이후 검증 MSE를 계산하고 가장 낮은 검증 MSE를 만든 모델을 따로 보관한다.
충분한 개선(기본 기준 0.00001)이 없는 상태가 40 epoch 지속되면 종료한다.
마지막 epoch 모델을 무조건 사용하는 대신 보관한 최선의 모델을 복원한다.

테스트 오차는 이 종료 판단에 사용하지 않는다.

### 5.7 처리 절차 요약

~~~text
입력변수와 목표변수를 선택한다
유효하지 않은 행을 제거한다
학습 / 검증 / 테스트 인덱스를 만든다
학습 데이터만으로 입력·목표 표준화 통계를 구한다
신경망을 초기화한다
매 epoch:
    학습 데이터로 순전파·역전파·Adam 갱신
    검증 데이터로 MSE 계산
    가장 좋은 가중치 보관
    조기 종료 조건 확인
최선 가중치 복원
테스트 데이터 예측 → 원래 목표 크기로 복원 → 평가지표 계산
새 입력에도 같은 표준화·신경망·역변환 적용
~~~

| 개념 | 코드 위치 | 설명 |
|---|---|---|
| 입력·정답 선택 | `models/neural_network.py`의 `prepare_data` | 선택한 여러 열을 X, 목표 열을 y로 구성 |
| 분리 | `split_indices` | 같은 선형번호를 한 세트에만 배치 |

| 가중치·편향 학습 | `network.partial_fit(X_train, y_train)` | 라이브러리 내부 순전파·역전파·Adam 갱신 |

역전파·Adam을 직접 구현한 것은 아니다. 라이브러리 사용과 데이터 분리·표준화·검증·설명 코드를 결합했다. 직접 경사하강법 코드를 작성해야 한다는 별도 조건은 확인되지 않았으며, 조건이 추가되면 재검토한다.

## 6. 평가지표

실제값 y, 예측값 ŷ, 평가 데이터 평균 ȳ를 사용한다.

$$
R^2=1-\frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}
$$
$$
\mathrm{RMSE}=\sqrt{\frac{1}{n}\sum(y_i-\hat y_i)^2},\qquad
\mathrm{MAE}=\frac{1}{n}\sum|y_i-\hat y_i|
$$

R²는 분류의 정답률이 아니다. 음수가 될 수 있고, 실제 목표값이 일정하면 이 구현에서는 정의 불가로 표시한다.
RMSE와 MAE는 예측값을 원래 크기로 복원한 뒤 계산하므로 목표변수와 같은 척도를 갖는다.
학습·검증·테스트 성능을 구분하고, 같은 학습 행과 입력변수로 학습한 선형회귀도 같은 테스트 세트에서 비교한다.

### 7.2 10월 3일 보강 실험: 은닉층 구조 비교

10/2 38:58의 구조 결정·테스트 지시를 반영한 **AI 지원 로컬 실행 결과**이다. 결과를 만들기 전에 후보를 (32), (32,16), (64,32), (64,32,16)으로 정하고, 입력 8개·목표 1개, 학습/검증/테스트 행, ReLU, 학습률 0.001, 최대 500 epoch, 조기 종료 대기 40, alpha 0.0001, 시드 42를 고정했다. 초기화에 같은 시드를 사용해 재현성을 확보했지만 구조 크기가 다르므로 초기 가중치 배열 자체가 같은 것은 아니다.

| 은닉층 노드 수 | 은닉층 수 | 파라미터 수 | 학습 RMSE | 검증 RMSE | 검증 R² | 실행/채택 epoch |
|---|---:|---:|---:|---:|---:|---:|
| 32 | 1 | 321 | 2.716548 | 5.868015 | 0.980861 | 405 / 365 |
| **32·16** | **2** | **833** | **2.229979** | **5.213467** | **0.984893** | **324 / 284** |
| 64·32 | 2 | 2,689 | 1.140840 | 5.825159 | 0.981140 | 221 / 181 |
| 64·32·16 | 3 | 3,201 | 1.145453 | 6.429084 | 0.977027 | 182 / 142 |

검증 RMSE가 가장 작은 **32·16**을 선택했다. 이 구조는 기존 64·32보다 파라미터 수도 적었다. 다만 선택 기준은 검증 RMSE이며, 파라미터 수를 별도 가중치로 점수화한 것은 아니다. 네 후보를 비교하는 중에는 테스트 예측·평가를 호출하지 않는다. 선택 후 보관한 모델을 테스트했다.

| 선택 구조 32·16 | 행 수 | R² | RMSE | MAE |
|---|---:|---:|---:|---:|
| 학습 | 640 | 0.997924 | 2.229979 | 1.488031 |
| 검증 | 176 | 0.984893 | 5.213467 | 3.799658 |
| 테스트 | 202 | **0.966472** | **9.485945** | **5.995285** |

**결과 해석:** 64·32는 학습 RMSE가 더 작지만 검증 RMSE는 더 컸다. 복잡도를 높이는 것만으로 새로운 관측에서의 오차가 줄지는 않았다. 32·16의 테스트 성능은 기존 64·32의 R²=0.972433보다 낮았다. 이 차이를 숨기지 않고, 이미 정한 검증 기준대로 32·16을 선택했다. 이번 보강을 테스트 성능 향상으로 주장하지 않는다.

**평가의 한계:** 검증 데이터를 epoch 선택과 구조 선택에 함께 사용했으므로 검증 성능에도 선택 효과가 있다. 특히 같은 테스트 세트가 10/2의 기존 모델 평가에서 이미 관찰됐으므로, 이번 수치를 완전히 새롭고 독립적인 최종 검증이라고 부를 수 없다. 한 번의 분할·시드만 사용했다. 모델 간 우열을 일반화하려면 새 선박 데이터나 별도의 그룹 교차검증이 필요하다. 이 문서에 그런 추가 실험을 수행했다고 기록하지 않는다.

### 7.3 실제 노드 하나의 계산

32·16 모델의 첫 학습 관측(필터 적용 후 결측 제거 전 12번째 행)에서 첫 은닉 노드를 확인했다. 8개 표준화 입력에 해당 가중치를 곱해 더한 값은 -0.892524, 편향은 0.387001이다.

$$
z = \sum_{i=1}^{8}\tilde{x}_i w_{i1}+b_1
\approx -0.892524+0.387001=-0.505523
$$
$$
h_1=\operatorname{ReLU}(z)=\max(0,-0.505523)=0
$$

이는 은닉 노드 하나의 출력이 0이라는 뜻이며 최종 저항 예측이 0이라는 뜻은 아니다. 나머지 노드와 층, 출력층, 역표준화를 더 거친다. 입력별 곱셈은 앱 화면과 `docs/ann_experiment/first_node_terms.csv`에서 확인한다.

## 8. 사용 방법

1. 앱 왼쪽에서 ‘인공신경망 (2차 과제)’를 선택한다.
2. 자동 선택되는 전체 변수 예제를 사용하거나 CSV·Excel 파일을 업로드한다.
3. 목표변수·입력변수·분리 방식·학습 설정을 확인한다.
4. ‘입력·출력 형태 이해하기’에서 행 수·변수 수와 X/y 형태를 확인한다.
5. ‘구조 비교 실험 실행’을 눌러 네 구조를 비교한다. 검증 RMSE 기준 선택과 파라미터 수를 확인하고 ‘비교에서 선택한 구조 적용’을 누른다.
6. ‘인공신경망 학습 시작’을 누른다. 적용한 설정으로 다시 학습하고 테스트 성능을 표시한다.
7. 가중치·편향과 노드 계산, 학습 곡선, 테스트 실제값·예측값, 잔차를 확인한다.
8. 아래 입력폼에 새로운 값을 넣고 ‘입력값 예측’을 누른다.
9. 구조 비교 CSV·JSON, 예측 결과 CSV, 학습 곡선 CSV, 설정·평가 JSON을 내려받는다.

입력폼 조작 때문에 불필요하게 재학습하지 않도록 세션에 결과를 보관한다.
원자료·선택 변수·학습 설정이 달라지면 이전 결과를 숨기고 재학습하도록 한다.
브라우저 새로고침이나 서버 재시작을 넘어 모델을 영구 저장하는 기능은 없다.
단일 구조만 학습하려면 5번은 생략할 수 있다. 학습률·시드·데이터가 바뀌면 구조 비교 결과도 숨겨 재실험하도록 한다.

## 9. 한계와 확인 사항

- 테스트 결과를 보고 설정을 반복 조정하면 테스트에도 간접적으로 맞춰지므로 최종 검증용 새 데이터가 필요하다.
- 선형번호가 달라도 같은 계열의 유사한 선박이므로 모든 새로운 선형에 대한 일반화를 보장하지 않는다.
- 학습 범위를 벗어난 외삽 및 물리적으로 불가능한 입력 조합은 신뢰하기 어렵다.
- 신경망 출력에 비음수 제약을 주지 않아 음수 저항을 예측할 수 있다.
- 이 프로그램은 교육용이며 실선 설계나 안전 판단용으로 검증한 모델이 아니다.
- 실제 배포 환경의 동작, 공개 링크의 접근 가능 여부 및 LMS 제출은 별도로 확인해야 한다.
- 은닉층 수·분리 비율·학습률·최소 행 수는 구현 선택이며 과제 공지의 필수 조건으로 제시된 것은 아니다.

### 강의 설명을 적용할 때 구분한 내용

- **다차원성과 비선형성:** 다중선형회귀도 여러 입력을 받을 수 있다. 신경망을 쓰는 이유를 ‘입력이 여러 개면 선형회귀가 불가능해서’라고 설명하지 않는다. 이 과제는 여러 입력 사이의 비선형 관계를 표현하는 모델을 실험하는 것이다.
- **편향과 층 수:** 편향은 위치를 바꾸지만 단독으로 비선형성을 만들지 않는다. 비선형 활성화 없이 선형/아핀 층을 쌓으면 전체도 선형/아핀 함수이다(10/2 12:04–14:01의 설명과 연결).
- **활성화 함수:** 10/2 40:36의 지수함수 형태 설명을 모든 활성화 함수에 적용하지 않는다. 이 구현의 ReLU는 지수함수가 아니다. 회귀 출력층은 항등함수를 사용한다. 수업의 일반 그림에서 모든 노드에 활성화를 그리더라도 출력층 함수는 과제에 맞게 선택한다.
- **새 데이터:** 10/2 20:48의 ‘학습되지 않은 데이터’는 일반화·분포 변화의 맥락을 구분한다. 처음 보는 관측에도 예측할 수 있지만, 학습 자료와 아주 다른 조건의 정확도는 보장되지 않는다. 생성형 AI 논의를 ‘데이터가 없어도 이 회귀모델이 정확히 학습된다’로 해석하지 않는다.

## 12. 내가 설명할 수 있어야 하는 핵심 질문 5개

아래 문항은 **AI가 만든 설명 연습용**이며 실제 시험 문항을 복원한 것이 아니다. 공식 채점 기준도 아니다. 특히 3번은 교수님의 10/2 18:21–19:20 및 9/30 27:44의 신경망 구조 설명 출제 언급과 연결된다.

1. **관측이 1,018개인데 입력 노드는 왜 8개인가?** 한 행은 관측 1건이고 한 관측의 입력변수가 8개이기 때문이다. X=(1018,8), y=(1018,), 출력 노드 1개라고 설명한다.
2. **내가 정하는 것과 AI가 학습하는 것은 무엇인가?** 입력·목표·구조·활성화·학습률은 설정하고, 가중치와 편향은 학습 데이터의 오차를 줄이도록 갱신한다.
3. **신경망 그림의 연결선·노드와 수식을 설명할 수 있는가?** 연결선은 가중치, 노드는 가중합에 편향을 더하고 활성화를 적용하는 계산이다. `z=Σwx+b`, `h=φ(z)`를 설명하고, 입력·은닉·출력층과 이 회귀 모델의 항등 출력층을 구분한다.
4. **왜 32·16을 선택했고 더 큰 구조를 쓰지 않았는가?** 고정된 네 후보에서 검증 RMSE가 가장 작았다. 테스트 최고 점수로 선택한 것이 아니며, 한 번의 실험에서만 확인한 결과다.
5. **무엇을 최소화하고, 이 예측을 얼마나 믿을 수 있는가?** 학습은 제곱오차 기반 손실과 규제를 사용하고, epoch·구조는 검증 오차로 고른다. 새 선박에 대한 분리 평가를 했지만 테스트 세트 재사용·분포 밖 입력·음수 저항·한 번의 분할이라는 한계가 있다.
