# 무료 CPU 버전 검증 기록

- 가상환경 패키지 설치 확인, 자동 검사 45개 통과.
- 실제 모델 요청 13개 중 12개 통과. 개인 이름 회상 1개 오답.
- 동작 분류 자체는 13개 모두 기대값. 회귀·신경망·epoch 비교·오차 조회·보고서·새 입력 예측·저장된 분석 복원 정상.
- Streamlit AppTest로 실제 모델을 호출하여 대화, 회귀 표·그래프, 방문자 대화 분리 확인. 이름 답변 내용 오류를 실패로 기록.
- 최대 프로세스 메모리 2195.1MiB (2.14GiB).
- 다운로드 후 LLM 처리 시간 18.3~33.2초, 중앙값 19.9초. CPU 2개를 사용하도록 제한한 개발 환경 수치이며 서버 속도 보장이 아님.

## 해석

작은 0.5B 모델은 앞선 시험에서 여러 분석 명령을 오분류하여 제외했다. 1.5B에서도 과거 대화가 동작 분류에 영향을 주는 문제가 있어, 현재 요청의 명령 선택과 일반 대화 생성을 분리했다. 사용자 이름 회상 오류는 남아 있으며 성공으로 처리하지 않는다.

모델 파일은 약 1.12GB이고 실행 메모리는 별도다. 공식 Streamlit 자원 제한은 변경될 수 있으므로 실제 무료 서버에 올려 RAM 제한과 공개 접속을 확인해야 한다. 유료 API를 사용하지 않으며 Hugging Face는 공개 파일 다운로드에만 사용한다.

## 완료하지 않은 일

실제 Streamlit Community Cloud 재배포, 로그아웃/다른 기기의 공개 URL 질문, 사용자 직접 캡처, LMS 제출은 미확인이다.

## 증거 파일

- actual_execution.json: 실제 모델 명령·생성 답변·분석 수치·처리 시간.
- ui_execution.json: 실제 모델을 사용한 Streamlit 화면 검사.
- automated_tests.txt, install.log, summary.json.

이 검증은 AI 개발 환경에서 수행했다. 사용자가 직접 수행한 실험이나 공개 서버에서 측정한 수치로 쓰지 않는다.
